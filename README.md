## 📝 ¿Qué estoy aprendiendo en este tema?

En esta primera etapa, me estoy familiarizando con la estructura de las páginas web. Aquí tienes un resumen de lo que voy viendo:

* **Estructura básica:** `<!DOCTYPE html>`, `<html>`, `<head>` y `<body>`.
* **Etiquetas de texto:** Títulos (`h1` a `h6`), párrafos (`p`) y énfasis.
* **Listas:** Organizando información con `<ul>`, `<ol>` y `<li>`.
* **Enlaces e Imágenes:** Conectando páginas y añadiendo contenido visual.
* **Tablas:** Empezando a estructurar datos de forma tabular.

---

## 🛠️ Mi primer "Esqueleto" HTML

Para no olvidarme de lo básico, aquí dejo el código que siempre uso de base:

```html
<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Mi Primera Página</title>
</head>
<body>
    <h1>¡Hola Mundo!</h1>
    <p>Este es mi primer párrafo mientras aprendo HTML.</p>
</body>
</html>
